# Hue

Hue is an AI-powered outfit intelligence app — a second opinion for what you're wearing, not a verdict. Built solo for the Hack Club Stardance challenge.

## Features (in progress)
- **Closet** — upload and organize your wardrobe
- **Suggest** — get outfit pairing suggestions from what you own
- **Score** — a supportive "mirror-check" score for your outfit
- **Ask Hue** — chat-based styling help
- **Circle** — opt-in sharing with friends

## Tech
Currently built with plain HTML, CSS, and JavaScript.
